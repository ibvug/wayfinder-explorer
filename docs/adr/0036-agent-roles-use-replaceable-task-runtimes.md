# Agent 是由可替换任务运行时承载的逻辑角色

Explorer 把地图 Agent 和探索 Agent 建模为具有稳定 Explorer 身份的逻辑会话，而不把 Codex 协议或 `threadId` 写入领域语义。当前运行时适配器将一个逻辑 Agent 会话一对一绑定到一个持久 Codex Thread；一个 Thread 对应一段可恢复对话并包含多个 Turn，在 Codex 产品界面中可以表现为一个 task 或会话。适配器统一提供开始、恢复、发送消息、请求结构化提案、中断、工具事件、权限请求和事件流，运行时绑定只属于基础设施状态。Agent 可以在权限边界内观察环境和使用工具；地图内容变化仍必须形成 Explorer 能够校验和呈现的提案。以后替换 Agent 实现时，只需更换运行时适配器和绑定，不需要改动地图领域、交互流程或持久化格式。
