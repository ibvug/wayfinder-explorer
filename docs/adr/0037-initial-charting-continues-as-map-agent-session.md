# 首图绘制会话继续承担整次地图维护

每次目标探索只有一个逻辑地图 Agent 会话：它依次主持建立目的地、建立起点和形成首图草案，在首图创建后仍保留稳定身份，并在答案确认或修订后继续形成地图变化提案。建立起点内部的背景沟通、取证边界和定向取证也发生在这个会话中，不会形成新的阶段会话；尚未确认的起点草案及其证据版本随会话持久保存，进程恢复后仍是可继续讨论或确认的草案，不会因此成为地图事实。当前 Codex 运行时将该会话绑定到一个可恢复的持久 Codex Thread，而不是在每次重新绘图时创建互不相关的新任务。Explorer 外置保存地图真源、会话身份和运行时绑定，因此 Codex 进程重启或未来更换 Agent 运行时都不会改变这次目标探索的身份与历史。
