# AI 负责协调答案变化的后续影响

探索者拥有目标与真实判断，AI 拥有地图的一致性维护职责。答案确认或修订后，AI 必须同时分析显式依赖和语义关联，自行更新所有可推导的议题、关系、路线、探索上下文和答案草案；探索者不需要逐节点、逐状态或逐份表示批准机械变化。只有既有探索者判断与新前提真实冲突、且无法从已表达意图可靠解决时，AI 才把冲突作为一个聚焦问题交还给探索者；答案确认后，AI 将结果协调到同一张图的全部相关内容。此决定取代 ADR-0030、ADR-0032、ADR-0033、ADR-0034 规定的强制逐节点复核、固定复核顺序、显式会话校准和草案重建流程，也取代 ADR-0015 对正在探索状态的过宽约束。
