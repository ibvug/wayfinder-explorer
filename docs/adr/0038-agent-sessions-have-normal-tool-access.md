# Agent 会话具有正常工具能力并以权限约束副作用

地图 Agent 和探索 Agent 当前都由正常 Codex Thread 承载，而不是只能消费预先整理文本的受限问答。Thread 可以在约定取证范围内读取文件、调用工具并观察最新环境，从而自行取得形成可靠判断所需的事实；Explorer 不需要把所有环境信息预先塞入提示词。写入普通项目文件、执行外部动作或产生其他副作用必须经过运行时沙箱和审批策略授权；规范地图内容的写入仍经过 Explorer 已有的地图预览与确认边界，普通运行时权限不能替代领域确认。未来替换 Agent 运行时时，新适配器也必须保留“可观察真实环境、按权限执行副作用”的能力契约。
